# M701JAC — Phase 2 target machine

After the Phase 1 submission the team chose a more modern machine: the **Mitsubishi Power M701JAC**, a 50 Hz J-series gas turbine with a 15-stage axial compressor, PR 25, 3000 rpm and ISO ratings of 448 MW and 574 MW.

| Folder | Content |
|---|---|
| [`sources/`](sources/) | Index of the MHI documents D1–D8 (official URLs and checksums; the PDFs are not redistributed) and the team's technical dossier |
| [`docs/ASSUMPTIONS_AUDIT.md`](docs/ASSUMPTIONS_AUDIT.md) | Every assumed number from Phase 1 and the dossier, what was wrong with it and what replaces it, including the supervisor's points on efficiency and stage loading. A Word version is alongside it. |
| [`docs/DOSSIER_REVIEW.md`](docs/DOSSIER_REVIEW.md) | Claim-by-claim check of the dossier against the source documents |
| [`analysis/`](analysis/) | `m701jac_analysis.py`: real-gas (Cantera) catalogue analysis with Monte Carlo uncertainty, an efficiency cross-check and a stage work-distribution model. `results_tables.md`, `results.json` and `fig_A`–`fig_F` are generated by it. |

Run the analysis with `pip install cantera numpy matplotlib`, then `python3 analysis/m701jac_analysis.py` (about 5 s).

## Headline results (448 MW rating; median, with 5–95 % band from the unpublished inputs)

| | |
|---|---|
| Inlet air flow | 743.8 kg/s (743.0–744.6), fixed by catalogue data |
| Delivery temperature | 789 K (771–809), dominated by the efficiency |
| Compressor power (full delivery flow) | 390 MW (375–407) |
| First-rotor tip diameter | 2.58 m (2.42–2.76) |
| First-rotor relative tip Mach | 1.33 (1.28–1.38): transonic, consistent with D6 |
| Stage pressure ratio | ≈ 1.35 (stages 1–2) falling to ≈ 1.12 (stage 15), not 1.239 in every stage |
